CV-CATALYST: AI-POWERED ATS RESUME BUILDER & CAREER SUITE
================================================================================
An Enterprise-Grade, Full-Stack SaaS Platform for AI Resume Optimization, 
Job Description Matching, and Server-Side High-Fidelity PDF Generation.

--------------------------------------------------------------------------------
1. EXECUTIVE OVERVIEW & PROBLEM STATEMENT
--------------------------------------------------------------------------------
Modern hiring relies heavily on automated Applicant Tracking Systems (ATS) 
such as Lever, Greenhouse, Workday, and Taleo, which reject over 75% of job 
applications before a human recruiter ever sees them. Resumes fail primarily 
due to missing target keywords, unparseable scanned file formats, non-standard 
layouts, and lack of quantifiable metrics.

CV-Catalyst solves this problem by using Google Gemini AI models to analyze 
target Job Descriptions (JDs), extract key skills and competencies, intelligently 
rewrite resume content to highlight relevant experience, calculate realistic ATS 
compatibility scores (0-100%), and render print-ready PDFs using server-side 
headless Chrome browser automation.

--------------------------------------------------------------------------------

  Razorpay Webhooks (payment.captured)

3. HOW IT WORKS (END-TO-END WORKFLOW)
--------------------------------------------------------------------------------
Step 1: Document Ingestion & Multi-Tier OCR Parsing
- User uploads a resume file (.pdf, .docx, .png, .jpg) or pastes text.
- Standard PDFs use pdf-parse; if text length is under 20 characters (indicating 
  a scanned image PDF), the system automatically routes the file buffer to 
  Gemini Vision OCR.
- Word (.docx) files are converted via mammoth.

Step 2: Job Description Intelligence (JD Agent)
- The analyzeJobDescription service prompts Gemini to extract standard job 
  titles, top 20 ranked keywords, non-negotiable "must-have" skills, optional 
  "nice-to-have" qualifications, and expected tone.

Step 3: Contextual Resume Optimization (Rewrite Agent)
- The rewriteResume service combines user experience with extracted JD context.
- Section bullets are re-engineered with strong action verbs, quantifiable 
  metrics, and optimal keyword density.

Step 4: Algorithmic ATS Scoring Engine
- Evaluates resumes across 3 pillars: Structure & Contact Completeness (35 pts), 
  Action Verbs & Quantifiable Impact (25 pts), and Job Description Keyword 
  Alignment (40 pts), yielding a final score from 0 to 100%.

Step 5: Server-Side PDF Rendering via Puppeteer
- Structured resume JSON is compiled into custom HTML/CSS print templates 
  (Classic, Modern, Minimal).
- Puppeteer launches an isolated headless Chromium browser, renders A4 pages 
  with Google Fonts (networkidle0 wait state), and returns a text-selectable 
  binary PDF stream to the user.

Step 6: Monetization & Subscription Flow
- Users can upgrade to Pro via Razorpay checkout.
- Orders are validated server-side using HMAC SHA256 signatures, and webhooks 
  automatically update user tier flags in MongoDB.

--------------------------------------------------------------------------------
4. KEY TECHNICAL ACHIEVEMENTS & INTERVIEW HIGHLIGHTS
--------------------------------------------------------------------------------
1. Multi-Model LLM Resilience & Fallback Architecture:
   Designed a fallback chain (gemini-1.5-flash -> gemini-2.0-flash -> gemini-1.5-pro 
   -> in-house regex/heuristic parser). If LLM APIs fail or rate limit, the system 
   seamlessly degrades to an internal dynamic parser, guaranteeing 100% uptime.

2. Dual-Mode Document OCR Extraction:
   Prevents failures on scanned PDFs or image uploads by automatically detecting 
   empty text buffers and triggering Gemini Vision OCR.

3. Headless Chrome Server-Side PDF Engine:
   Avoids canvas-based client libraries (like html2canvas) which create non-selectable 
   rasterized images that fail ATS screeners. Puppeteer creates 100% text-selectable, 
   vector-crisp A4 PDFs.

4. Cryptographic Payment Verification:
   Ensures tamper-proof payment processing via Razorpay HMAC SHA256 signature 
   verification and asynchronous webhook fulfillment.
