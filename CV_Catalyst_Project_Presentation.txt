1. EXECUTIVE SUMMARY & PROBLEM STATEMENT
--------------------------------------------------------------------------------
THE PROBLEM:
In modern recruitment, over 75% of job applications are automatically rejected 
by Applicant Tracking Systems (ATS) like Lever, Greenhouse, Workday, and Taleo 
before reaching a human recruiter. Standard resumes fail due to:
1. Missing role-specific target keywords.
2. Unparseable file formats or low-quality scanned image PDFs.
3. Lack of quantifiable achievement metrics.
4. Non-standard visual layouts that confuse ATS parsers.

THE CV-CATALYST SOLUTION:
CV-Catalyst is an end-to-end AI career suite that optimizes candidate resumes 
against specific target job descriptions in seconds. Using Google Gemini AI, 
native document parsers, Gemini Vision OCR, and server-side Puppeteer Chrome 
rendering, CV-Catalyst converts raw resumes into keyword-optimized, 
high-scoring, ATS-compliant PDF applications.

2. SKILLSET MATRIX & TECH STACK BREAKDOWN
--------------------------------------------------------------------------------
FRONTEND ARCHITECTURE (React 19 + Vite 8):
- Framework: React 19 Single Page Application (SPA)
- Build Tool: Vite 8 with Fast HMR
- UI & Styling: TailwindCSS v4, Material UI (MUI v9), @emotion/styled, Lucide React
- State & Forms: React Hook Form, React Context API (Auth & Global State)

BACKEND SERVICES (Node.js + Express 5):
- Runtime & Server: Node.js, Express 5 RESTful API Gateway
- Session Auth: Passport.js (Local Strategy), passport-local-mongoose
- Session Persistence: Connect-Mongo with MongoDB Session Store

AI & DOCUMENT PROCESSING:
- LLM Service: Google Generative AI SDK (@google/generative-ai)
- Models Used: Gemini 1.5 Flash, Gemini 2.0 Flash, Gemini 1.5 Pro
- Computer Vision: Gemini Vision OCR API (for scanned PDFs & image uploads)
- Document Parsers: pdf-parse (native text PDFs), mammoth (Microsoft Word .docx)
- Rendering Engine: Puppeteer v25 (server-side headless Chrome A4 PDF generator)

DATABASE & MONETIZATION:
- Database: MongoDB with Mongoose v9 schemas (User, Resume, Subscription)
- Payment Gateway: Razorpay API, HMAC SHA256 cryptographic signature validation, 
  Razorpay Webhooks (payment.captured)

3. HOW IT WORKS (SYSTEM ARCHITECTURE & DATA FLOW)
--------------------------------------------------------------------------------
Step 1: Document Ingestion & Multi-Tier OCR Parsing
  User uploads a resume file (.pdf, .docx, .png, .jpg) or pastes plain text.
  Backend checks file type: native text PDFs use pdf-parse; if text is below 
  20 characters (scanned image PDF), it dynamically routes the buffer to 
  Gemini Vision OCR. Word (.docx) files are processed by mammoth.

Step 2: Job Description Intelligence (JD Agent)
  When a target job description is provided, the analyzeJobDescription service 
  prompts Gemini to extract standardized job titles, top 20 ranked keywords, 
  "must-have" hard requirements, "nice-to-have" qualifications, and communication tone.

Step 3: Contextual Resume Optimization (Rewrite Agent)
  The rewriteResume service combines user experience with extracted JD context. 
  It re-engineers resume bullets with strong action verbs, quantifiable metrics, 
  and natural keyword alignment.

Step 4: Algorithmic ATS Scoring Engine
  Evaluates rewritten resumes across 3 key pillars:
  - Structure & Contact Completeness (up to 35 pts)
  - Action Verbs & Quantifiable Impact (up to 25 pts)
  - Job Description Keyword Alignment (up to 40 pts)
  Calculates a final match score from 0% to 100%.

Step 5: Server-Side PDF Rendering via Puppeteer
  The structured resume JSON is injected into print-optimized HTML/CSS templates 
  (Classic, Modern, Minimal). Puppeteer launches a headless Chromium instance, 
  renders A4 pages with Google Fonts, and streams a text-selectable PDF to the client.

Step 6: Monetization & Subscription Management
  Users upgrade to Pro via Razorpay checkout. Server verifies HMAC SHA256 signatures 
  and handles asynchronous payment.captured webhook notifications to update MongoDB.

5. COMPANY PRESENTATION PITCH & TECHNICAL INTERVIEW TALKING POINTS
--------------------------------------------------------------------------------
30-SECOND ELEVATOR PITCH:
"CV-Catalyst is a full-stack SaaS career platform built with React 19, Node.js, 
Express, MongoDB, and Google Gemini AI. It solves the problem of automated ATS 
resume rejections by extracting text from resumes (including scanned documents 
via OCR), analyzing target job descriptions, rewriting resume sections for 
maximum keyword alignment, and rendering true text-selectable A4 PDFs using 
server-side Puppeteer Chrome automation."

KEY ENGINEERING HIGHLIGHTS TO MENTION IN INTERVIEWS:

1. Multi-Tiered AI Fallback & Resilience:
   Built a high-availability fallback architecture for Gemini AI calls. If Gemini API 
   rate limits occur or network errors happen, the system gracefully degrades to an 
   in-house dynamic heuristic parser (parseResumeTextDynamically) using regular 
   expressions and section slicing, guaranteeing 100% uptime for resume creation.

2. Dual-Mode Document OCR Extraction:
   Native text parsers fail on scanned PDFs and images. CV-Catalyst uses native 
   pdf-parse for standard PDFs, but automatically detects empty/scanned buffers 
   and routes them to Gemini Vision OCR, extracting text seamlessly regardless of format.

3. Server-Side Headless Chrome PDF Engine:
   Avoided client-side canvas libraries (like html2canvas/jsPDF) which create 
   non-selectable rasterized images that fail ATS parsers. Used Puppeteer on the 
   server to compile custom CSS A4 templates with Google Fonts, yielding vector-crisp, 
   text-selectable PDFs.

4. Secure Cryptographic Payments:
   Implemented Razorpay payment integration backed by HMAC SHA256 server-side 
   signature validation and async webhook processing to ensure tamper-proof upgrades.
